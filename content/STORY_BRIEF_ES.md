# Spanish story authoring brief (graded reader)

Read `content/STORY_BRIEF.md` first: schema, level table, lexicon sidecar format, check loop and finishing rules all apply. This file lists only the differences for SPANISH (language code `es`, Spain-neutral vocabulary, no vosotros/voseo; use tú/usted).

- Story file `content/raw/es-<name>.json`: `id` equals the file name and starts with `es-`; add top-level `"lang": "es"`. The key `fr` in each sentence holds the SPANISH text (the key name is historical); `en` is the English translation.
- Lexicon sidecar `content/lexicon/stories/<id>.lex` (there is no shared Spanish lexicon yet, so the sidecar must define EVERY word). Same L/F/P line formats.
- Tokens: no elision, so each Spanish word is one token (`del` = `de` + el and `al` = `a` + el are single tokens: map `del` -> `de` PREP note `de + el`, `al` -> `a` PREP note `a + el`). Punctuation including ¿ ¡ is not a token. Clitic pronouns written separately (`me`, `se`, `lo`, `la`) are their own tokens; avoid attached clitics (dámelo, lavarse in running text is fine as an infinitive form).
- Lemmas: verbs = infinitive (`ser`, `ir`; reflexives as `lavarse`), nouns = singular with gender `m`/`f` (the app shows el/la itself; only set the article column for exceptions such as `el` with feminine `agua`: article `el`), adjectives = masculine singular. Plural/feminine surface forms get F lines with notes `plural`, `feminine`, `feminine plural`.
- Form-note vocabulary for tenses: `presente (yo)`, `presente (él/ella)`, `presente (nosotros)`, `presente (ellos)`, `imperative (tú)`, `infinitive`, `gerundio`, `participio`, `pretérito (él/ella)`, `imperfecto (él/ella)`, `futuro (él/ella)`, `condicional (yo)`, `subjuntivo presente (que él)`.
- A1 Spanish: present tense (ser, estar, tener, ir, querer, gustar, hay, poder) plus simple imperatives and `ir a + infinitive`; sentences 4-9 words, never over 10; 170-250 words; high-frequency vocabulary; 3-5 repetitions of key vocab. Natural Spanish, correct accents and punctuation (¿?, ¡!), no digits (write numbers as words), plain apostrophes not needed.
- Quiz: add a top-level `"quiz"` array after `"chapters"` with exactly 3 questions: `{"q": Spanish question, "q_en": English, "o": [{"fr": Spanish option, "en": English} x3], "a": correct index (vary), "why": one English sentence pointing at the story}`. Simple A1 Spanish, literal comprehension, beginning/middle/end.
- Check: `python3 -I tools/build.py --check content/raw/<id>.json` until `-> clean`. Never run build.py without --check. Touch only your own files.
